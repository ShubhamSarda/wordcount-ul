# WordCount

WordCount is a React app that counts characters and words as you type or paste text. Use **Clear** to reset both counts. The `/joke` route shows a random joke fetched from the Chuck Norris API.

## Run locally

Use Node.js **26.13.1**. The app uses React and React DOM **19.3.1** and React Router DOM **6.30.6**.

From the project folder, run the following commands:

```sh
npm ci
npm start
```

Open [localhost:3000](http://localhost:3000) to use the counter. Run `npm run build` to create a production build in `build/`.
